# Mission Built

### A Field Guide for Building Things That Matter

By Mike Nichols • Second Edition • 2026

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/) [![Read online](https://img.shields.io/badge/read-missionbuilt.io-1f6feb.svg)](https://missionbuilt.io)

---

*Mission Built* is an open-source book about building things that matter (products, teams, and yourself), written by a former military intelligence analyst, product leader, and powerlifter. It pairs the discipline of the barbell with the demands of the boardroom, and argues that the same thing makes you good at both: showing up with purpose, even when no one's watching.

The motto is from VMM-364, a Marine tiltrotor squadron known as the Purple Foxes: **give a shit.** That phrase runs through every chapter.

## 📖 Read the book

The canonical reading experience is at **[missionbuilt.io](https://missionbuilt.io)**.

This repository is the open-source source-of-truth for the manuscript. Read it here on GitHub if you prefer. The book is available three ways:

- **Single file:** [`manuscript.md`](manuscript.md). The entire book in one file.
- **Chapter by chapter:** [`book/`](book). Each chapter, the prologue, sources, and back matter as separate files. Chapter file numbers match the book's chapter numbers (e.g., Chapter 7 lives in `book/07-train-the-engine.md`).
- **Online:** [missionbuilt.io](https://missionbuilt.io). Formatted for browser reading.

## 🆕 What changed in the second edition

See [CHANGELOG.md](CHANGELOG.md) for the full list. Highlights:

- New chapter: **AI Is the New OS** (Chapter 13).
- New front-matter note: **A Note on the Second Edition.**
- Tightened prose throughout. Roughly 1,700 words cut for spine and clarity.
- Updated examples for 2024–2026 (Cursor, Linear, Dovetail, Anthropic, Change Healthcare, Air Canada).
- Curated **Sources** section replacing the prior open-ended Further Reading list.
- Restructured **Acknowledgments**.
